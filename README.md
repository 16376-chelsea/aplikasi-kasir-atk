# Aplikasi Kasir dan Stok ATK

## Deskripsi
Aplikasi berbasis web untuk membantu pengelolaan
produk, stok barang, dan transaksi penjualan toko ATK.

## Fitur Utama
- Login dan logout
- Dashboard
- Pengelolaan kategori produk
- Pengelolaan data produk dan stok
- Pencatatan transaksi penjualan
- Pencarian produk

## Teknologi
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Status Proyek
Tahap perencanaan dan persiapan proyek.
